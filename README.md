# Uoink Homebrew tap

```sh
brew install --cask ryanbiddy/uoink/uoink
```

Installs [Uoink](https://uoink.app) for macOS 15 or later on Apple Silicon and
links the `uoink` command. `brew uninstall --cask uoink` removes the app but
leaves your saved library in `~/Library/Application Support/Uoink`.

Source and releases: https://github.com/ryanbiddy/uoink
